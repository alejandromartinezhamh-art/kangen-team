# Anuncios de Rocío

Un archivo por campaña: `AAAA-MM-nombre-campana.md`.

Cada archivo incluye: objetivo, público, textos (titular, texto principal, descripción), creatividades, landing de destino (`/l/<clave>`), presupuesto, fechas y resultados (leads, coste por lead).

Antes de lanzar, repasa la checklist de `estrategia/normas-comunicacion.md`.
