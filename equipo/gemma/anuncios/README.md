# Anuncios de Gemma

Los anuncios se gestionan en Notion → **CONTENIDO Y ANUNCIOS → Anuncios**: pieza de origen, presupuesto, gasto, leads,
leads cualificados y coste por lead cualificado. Los prepara el agente de anuncios a partir de las piezas que mejor
funcionan; nada se lanza ni sube de presupuesto sin aprobación de Gemma.

Antes del primer anuncio de pago: respuesta por escrito de Enagic (ver `estrategia/marketing.md`, sección 3) y la
checklist de `estrategia/normas-comunicacion.md`.

Aquí se guardan, si hace falta, las creatividades finales de cada campaña: `AAAA-MM-campana/`.
